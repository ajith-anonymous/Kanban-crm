# 🪄 Kanban CRM — Deal Management Made Visual

A modern and interactive **Kanban-style CRM** to manage **Won** and **Lost** deals with style.  
Built using React, featuring drag & drop cards, smooth animations, and confetti when deals are won 🎉

---
Preview - https://kanban-crm-azure.vercel.app/

## ✨ Features

- 📊 Kanban board for deal tracking  
- 🖱️ Drag & drop between columns  
- 🆕 Add / ✏️ Edit / 🗑️ Delete deals  
- 🔍 Search & filter deals  
- 🪄 Smooth UI animations & hover effects  
- 🎊 Confetti celebration on “Won” deals  
- 💻 Fully responsive layout

---

## 🧰 Tech Stack

- ⚛️ [React](https://react.dev/)  
- 🪶 CSS animations  
- 🎯 JavaScript (ES6+)  
- 🧰 (Optional) Tailwind CSS

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/ajith-anonymous/Kanban-crm.git

# 2. Navigate to the project folder
cd kanban-crm

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
